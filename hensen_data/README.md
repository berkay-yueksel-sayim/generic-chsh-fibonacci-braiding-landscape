# Hensen et al. (2015) open Bell-test data

`bell_open_data.txt` is the raw data file from:

B. Hensen, H. Bernien, A. E. Dréau, A. Reiserer, N. Kalb, M. S. Blok,
J. Ruitenberg, R. F. L. Vermeulen, R. N. Schouten, C. Abellán, W. Amaya,
V. Pruneri, M. W. Mitchell, M. Markham, D. J. Twitchen, D. Elkouss,
S. Wehner, T. H. Taminiau, R. Hanson,
"Loophole-free Bell inequality violation using electron spins separated
by 1.3 kilometres", Nature 526, 682 (2015),
doi: [10.1038/nature.15759](https://doi.org/10.1038/nature.15759).

Openly deposited by the authors at 4TU.ResearchData alongside the
publication. Column layout follows the authors' own
`bell_open_data_header.ods` (not included here; see the original
4TU.ResearchData record for the full file set and column definitions).

Used here only as an independent, unrelated experimental platform for
the null-control test in `../d7_acf_hensen2015_null_control.py`
(Sec. VI.C of the paper): re-prepared, independently heralded Bell
trials lack the shared-fusion-space memory mechanism the paper's own
prediction (Sec. VI, Table tab:acf) depends on, so no signal is
expected here, and none is found.
